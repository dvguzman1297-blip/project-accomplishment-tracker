# Project Accomplishment Tracker

Next.js 14 (App Router) + Supabase (`tracker` schema) + Tailwind. Admin-only.

## Setup
1. **Supabase SQL Editor:** run `supabase/01_schema.sql`, then `supabase/02_seed.sql`.
   (If you ran the earlier draft schema, run `drop schema tracker cascade;` first.)
2. **Project Settings → API → Exposed schemas:** add `tracker`.
3. **Authentication → Providers → Email:** turn off "Allow new users to sign up", then
   **Authentication → Users → Add user** to create your admin account (any authenticated user is an admin).
4. `cp .env.local.example .env.local` and fill in the project URL + anon key.
5. `npm install && npm run dev` → http://localhost:3000

## Notes
- `contracts` mirrors the workbook's "Maintenance File" columns. `start_date` (= NTP) and `expiry_date`
  (= NTP + CD − 1) are generated by Postgres, same as the sheet's formulas.
- The seed's three accomplishments on the first contract are sample entries for the charts.
- "Past expiry" is computed in the app (expiry date before today in Philippine time and not completed).
- Optional: `npx supabase gen types typescript --schema tracker` for generated DB types.
